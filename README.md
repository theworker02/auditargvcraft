# auditargvcraft

Audit encode/decode helpers for argv payloads in pipelines.

**Site:** https://theworker02.github.io/auditargvcraft/

## Install / run

```bash
git clone https://github.com/theworker02/auditargvcraft.git
cd auditargvcraft
node src/cli.js
node --test
```
